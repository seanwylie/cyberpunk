# Base body: license notes (Warranty Void, phase 1)

**Asset:** MakeHuman 1.1 base mesh `hm08` (`makehuman/data/3dobjs/base.obj`), plus macro targets
`{african,asian,caucasian}-{male,female}-young.target` and `universal-{male,female}-young-maxmuscle-averageweight.target`
(`makehuman/data/targets/macrodetails/`).

**Source:** https://github.com/makehumancommunity/makehuman (master), downloaded 2026-10-13.

the base mesh and proxies, targets and modifiers, textures, clothes, poses and expressions. These assets have been released under CC0 1.0 Universal."
Copyright holders at release: Data Collection AB, Joel Palmius, Jonas Hauquier (targets: originally Manuel Bastioni, transferred 2016).

**Commercial use:** allowed with no attribution or share-alike requirement, so BVG can ship it. A courtesy credit is optional.
**What we did NOT use:** we use no MakeHuman *application code* (AGPL), no MPFB add-on code (GPL) and no third-party community assets (mixed licenses).
