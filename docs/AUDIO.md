# Audio

## Music (ElevenLabs, `music_v1`, instrumental)
Generated by `tools/gen_music.py` (`ELEVENLABS_API_KEY=… python3 tools/gen_music.py [name…] [--force]`; needs ffmpeg). Raw downloads are cached in `tools/.music_raw/` (gitignored); outputs are loudness-normalised (-16 LUFS) 112 kbps stereo mp3 in `public/audio/music/` (~6.5 MB total).
Loop tracks get their last 2 s equal-power-blended onto their first 2 s, so they loop seamlessly (~71 s final length).

| File | Use | Style | Length |
|---|---|---|---|
| town | town | lo-fi trance/techno, ~108 bpm, unobtrusive | 71 s loop |
| traversal_a / _b | run traversal (2 variants) | lo-fi trance/techno, 118 / 122 bpm, mild tension | 71 s loops |
| combat_a / _b | combat (2 variants) | drum & bass 174 bpm, reese / neurofunk bass | 71 s loops |
| boss_reveal | boss entrance | drone → bass motif → impact | 28 s one-shot |
| boss_fight | boss combat | DnB 172 bpm, signature bass motif | 76 s loop |
| clear | after boss kill | subdued resolution | 24 s one-shot |

Prompts live in `tools/gen_music.py` (`TRACKS`). To change a track edit its prompt and run with `--force` (delete the raw cache file to re-request).

### Runtime (`src/music.ts`, hooked in `src/audio.ts`)
- States: town, traversal, combat, bossreveal, bosscombat, resolution (driven by `Game` `music` events).
- Equal-power (sin/cos) crossfades: 3 s town↔run, 1.5 s combat in, 2 s combat out, 2.5 s boss reveal in, 0.6 s reveal→fight, 0.5 s into the clear sting.
- Loop tracks remember their position when faded out and resume there; one-shots restart.
- Combat hysteresis: min 6 s in combat, then 4 s calm required before returning to traversal (`COMBAT_MIN`, `COMBAT_EXIT_HOLD`).
- Variants picked randomly per run; 35% chance to swap variant on re-entry. Reset on return to town.
- Unlock: context is created/resumed on first user gesture (existing `audio.resume()`); files load then. Procedural music plays until files finish decoding and when any file is missing/fails (automatic fallback).
- Volume hooks: `audio.setVolume` (master), `audio.setMusicVolume(0..1)`, `audio.setMusicOn`.
- Test: `npm run test:music` (needs dev server on :5173 and Chrome).
