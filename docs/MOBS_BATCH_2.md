# Mobs batch 2: tier-progressive mob rosters (28 new mobs)

Generated by `tools/gen_mobs_doc.mjs` from the data files. Tests: `tests/mobs2.mjs`. Art: `tools/enemies3d/specs_batch2.py` + `arch_batch2.py`. PLACEHOLDER balance, not approved numbers.

## 1. Design

- **4 tiers x 7 mobs.** Each tier introduces seven mobs; deeper levels field the new tier's mobs *and* mix back the older ones (levels of tier N never field a mob of tier > N).
- **Roles (11):** swarmer, bruiser, ranged, caster, support, shielded, exploder, summoner, sniper, charger, healer, debuffer. Every level mixes at least four of them.
- **Behaviour = the mechanics toolkit.** A mob's special attack is a `MoveSpec` (fan / ring / cross / marks / rain, same as the bosses) compiled to `<mob>.<n>`. Six mob-only attacks have small runtime code in `src/content/mobs.ts`: `snipe` (long telegraph, fast heavy bolt), `mend` (heal the most wounded ally), `ward` (shield nearby allies), `hex` (hit + slow + heat), `detonate` / `detonate_big` (self-destruct blast), `summonlite` (minions, cap 4 per summoner). Shielded mobs use the boss shield rule: damage is absorbed until the shield breaks, which staggers the mob (+50% damage, 2.5 s).
- **Stat scaling by tier** (authored per mob; averages): HP 33 -> 60 -> 104 -> 187, damage multiplier 1.19 -> 1.31 -> 1.64 -> 1.91, XP 14 -> 23 -> 38 -> 66.
- **Clearance classes:** radius <= .5 class 0, <= .72 class 1 (same flow classes as the other enemies); all mobs spawn only on tiles with clearance for their class and the level validator rejects layouts where one cannot reach.

## 3. Art

All 28 are rendered through the Blender pipeline (`tools/enemies3d`), 8 directions, idle / walk / attack / hit / death. They use **four new archetypes** (so they are not recolours of the existing ones) plus new extras on the old rigs:

- `crawler`: six-legged low skitterer (Cinder Mite, Fuse Crawler with a glowing sac, Dust Roach with a stinger, Repo Crawler).
- `orb`: floating core with spinning rings (Soot Wisp, Mender Wisp, Sedative Bloom, Relay Node, Purge Beacon).
- `tread`: tracked hull + turret (Bulwark Tread with plow and front shield, Mortar Tread, Tag Carrier kennel rack, Sweeper Mk II).
- `stilt`: tall two-legged rifle walker (Long-Lens Marksman, Reclaim Walker).
- quad extras `ram`, `plates`, `crates`, `coat` (Scrap Ram, Rebar Crusher, Pack Mule, Static Pup); humanoid extras `shield`, `satchel`, `hood`, `syringes` and the existing weapons.

Repo-size choices: frames are rendered at 192 px and packed at **96 px cells** in WebP (q86), with a lighter clip set (`ENEMY_LITE=1`: idle 4, walk 6, attack 7 (impact on 3), hit 2, death 6 frames). Atlases load lazily through the existing LRU in `src/enemyart.ts`. Contact sheet: `docs/mobs_batch2_contact.png`.

## 4. Elite affixes and pack rules

Every non-single pack is a **squad** of mixed roles under one alert group. The generator rolls one pack leader per squad: chance and number of affixes rise by tier (TI 10% / 1 affix, TII 18% / 1 affix, TIII 28% / 2 affixes, TIV 40% / 3 affixes). An affixed leader has x(1.6 + .25 per affix) HP, shows its affixes and an HP/shield bar, gives 2.5x XP and rolls the elite loot table.

| Affix | From tier | Effect |
|---|---|---|
| Hasted | I | +30% move speed, attacks faster |
| Volatile | I | explodes on death |
| Shielded | II | spawns with a 50% HP shield |
| Regenerating | II | regains 2.5% HP/s while out of combat damage |
| Vampiric | III | melee hits heal it |
| Frenzied | III | below 40% HP: +35% speed, +40% attack rate |
| Warded | IV | immune to damage for 2s after dropping below 50% (once) |

Vampiric and Frenzied only roll on mobs with a melee attack; static guns never become elites. Squad templates per zone (see `batch2_rosters.ts`):

- **yard:** legacy frontline + ranged, a swarm squad, a small squad of the level's first new mob.
- **proc (main fight):** new front + old front + ranged + support (tier >= 2); a swarm + charger squad; a ranged / shielded / support squad.
- **junction (pre-boss):** shielded or front + ranged + support; a caster/ranged battery.
- **salvage:** small swarm + exploder squad (clinic levels, which have no swarmers, get a front + ranged squad).

A second, half-size pass of every squad (not salvage) keeps the batch-1 enemy density (40+ enemies).
