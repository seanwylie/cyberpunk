# Ability audit

Generated by `tests/ability_audit.mjs` (headless: every ability cast in a real run against 4 frozen dummies with auto-attack suppressed, 8.5s of sim each, VFX events fed through the pooled VFX system). 78 abilities (10 core + 68 augment); 0 flagged by the final run.

**Columns.** *Effect measured*: state changes seen in the sim (beyond noise). *Visibility*: particles spawned by the ability's VFX profile plus whether a world-visible entity / ring is drawn (deployable, ally, projectile, zone, buff ring). *Viability*: 0-100. Damage abilities score damage-per-heat against auto-attack's damage-per-heat (5.0 dmg per heat), +12 if they also carry control/utility; others start at 100; -10 each for heat > 40, cooldown > 25s, wind-up > 0.8s. Pass needs >= 40 and >= 10 particles.

Decoy Projector rules (asserted in the test): spawns a decoy with >= 5 tile taunt radius; alerted non-boss enemies target it and walk to it; their attacks hit it, not you; an enemy projectile aimed through it is absorbed; it expires, the taunt ends, the end blast damages the crowd. Party play is client-authoritative (each client runs its own enemy AI), so the decoy is local to the caster's own enemy copies, like every other summon; no server change.
